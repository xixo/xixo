uris catalogs files and records that already live somewhere else. You attach the places they live,
such as buckets, directories, mailboxes, calendars, feeds, wikis, and repositories. uris reads each
one and builds a single index over all of them. You can search that index, ask questions of it, and
export from it. The bytes stay in their original places. uris stores where each thing lives and
what its analysis found.

Two interfaces reach the same catalog. The browser app uses [GraphQL](/reference/graphql/), and
the [MCP endpoint](/concepts/agents/) serves a model. Both accept the same access token, which
[masks](https://github.com/masksrb/masks) issues. Each interface calls the domain layer directly,
and neither is built on the other.
