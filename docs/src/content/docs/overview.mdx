xixo catalogs files and records that already live somewhere else. You attach the places they live,
such as folders on your machines, buckets, mailboxes, calendars, RSS feeds, Notion, and git
repositories. xixo reads each one and builds a single index over all of them. You can search that
index, ask questions of it, and export from it. The bytes stay in their original places. xixo stores
where each thing lives and what its analysis found.

Two interfaces reach the same catalog. The browser app uses [GraphQL](/reference/graphql/), and
AI agents use the [MCP endpoint](/concepts/agents/). Both accept the same access token, which
[masks](https://github.com/masksrb/masks) issues.
