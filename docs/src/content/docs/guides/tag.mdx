---
title: Tag items
description: Tag an item from its page, remove a tag, and tag what an answer drew on.
---

At the end of this guide, the items you chose are filed under a tag of your own, and the tag's page
lists them. Analysis also tags every item it reads. A tag you add stays when the item is analyzed
again. See [edges](/concepts/feeds/#edges).

## Tag an item

1. Open the item's page.
2. Open the menu beside the item's title and choose **Tag**. When the item already has tags, the
   field that reads **Add a tag** is already open under them.
3. Type the tag's name. The field suggests the tags that already exist.
4. Choose **Tag**.

A tag that does not exist yet is created. Case does not matter, and underscores read as spaces, so
`Mortgage_Statement` and `mortgage statement` are one tag.

## Remove a tag

1. Open the item's page.
2. Choose the remove button beside the tag.

## Tag what an answer drew on

1. Open the note that holds the answer.
2. Under **What it drew on**, choose **Tag these**. Every file and note in the list is checked.
3. Uncheck the items you want to leave out.
4. Type the tag's name in the field that reads **Tag the ones you have checked**.
5. Choose **Tag**. With more than one item checked, it reads **Tag** and the count, such as
   **Tag 3**.

Only files and notes can be checked. To stop without tagging, choose **Cancel**.

## Find what a tag holds

Choose a tag on any item's page. The tag's page lists everything filed under it.

## Over GraphQL

`tagFeeds` takes up to 200 item ids and a tag's name. It needs `xixo:catalog:write`. Pass
`tagged: false` to remove the tag instead.

```graphql
mutation {
  tagFeeds(input: { ids: ["41", "42"], tag: "lease" }) {
    feeds { id tags { key } }
  }
}
```

The `feeds` query takes a tag's name as `tag` and lists the items under it. See the
[GraphQL reference](/reference/graphql/).

## If it doesn't work

- **`a tag, type or address cannot itself be tagged`.** One of the ids is a tag, a content type, or
  an address. Only files and notes take tags.
- **`no more than 200 items can be tagged at once`.** Split the ids into several calls.
- **A removed tag comes back.** The item was analyzed again, and the analysis found the same tag.
