---
title: Ask the catalog
description: Ask a question from the search bar, follow it up, and keep what the answer found.
---

At the end of this guide, you have an answer kept as a note, with links to what it drew on. You need
a model backend with an **Agent model**. See [attach a resource](/guides/attach-a-resource/).
For how an answer is worked out, see [asking](/concepts/agents/#asking).

## Ask a question

1. Type the question in the search bar, where it reads **Search, ask, or paste an address**. Press
   `/` to reach it from anywhere. A question can be up to 500 characters.
2. Wait for the results. Above them, a row reads **Ask about** followed by your question.
3. Choose that row. From the search bar, `Tab` or `Down` moves to it and `Enter` asks.

xixo creates a note keyed by the question and opens its page. The question appears under **The
conversation**, with progress while the answer is worked out. When the answer is in, the note is
titled with what it found.

## Ask about one item

1. Open the item's page and choose **Ask about this**.
2. Type the question, and choose **Ask**.

The note is connected to the item, and the answer reads that item first, so "this" and "it" mean
that item. **Ask about this** does not appear on a note that was itself asked, or on the page of a
tag or a content type.

## Read the answer

The conversation lists the newest question first. Each item the answer cites is a link to that
item's page, and a page it read on the web is a link to that page. Below the answer, **What it drew
on** lists every item it cited. The note is connected to each of them.

## Follow up

1. On the note's page, type in the field that reads **Ask a follow-up**.
2. Choose **Ask**.

A follow-up starts from the earlier questions, their answers, and what they drew on. The field is
disabled while an answer is still being worked out.

## Ask again

1. Open the menu beside the note's title.
2. Choose **Ask again**.

xixo asks the latest question again and adds the new answer at the top.

## Keep what the answer found

The note lasts until you forget it. A note or page snapshot the agent made while answering lasts 30
days. See [lifetime](/concepts/feeds/#lifetime).

1. Open the item from **What it drew on**. Its page shows **forgotten** followed by the date.
2. Choose **Keep forever**.

To tag what the answer drew on, see [tag items](/guides/tag/#tag-what-an-answer-drew-on).

## Forget the note

1. Open the menu beside the note's title.
2. Choose **Forget**.
3. Choose **Forget it**.

## Over GraphQL

`askCatalog` takes a `question` and returns the note as `feed` and the analysis that answers it as
`analysis`. It needs `xixo:catalog:write`.

```graphql
mutation {
  askCatalog(input: { question: "When does the lease renew?" }) {
    feed { id }
    analysis { id status }
  }
}
```

Watch the analysis with the `analysisProgressed` subscription. When it is done, `said` holds the
answer and `drewOn` holds what it drew on. Pass the note's id as `feedId` to follow up, or an item's
id as `aboutId` to ask about it. See the [GraphQL reference](/reference/graphql/).

## If it doesn't work

- **No Ask about row.** The search bar treats text that looks like an address as something to keep,
  and offers that instead.
- **`no inference resource serves the agent role`.** No model backend names an **Agent model**. On
  **Resources**, open the backend's **More** menu, choose **Change**, and fill in **Agent model**.
- **`... is still being answered`.** Wait for the previous answer to finish, then follow up or ask
  again.
- **The answer names nothing from the web.** The tenant has no **Web search**, **Fetch a page**, or
  **The web** resource, so only the catalog was asked.
- **An error about `XIXO_INFERENCE_ORIGINS`.** The model backend's origin is not allowed. See
  [attach a resource](/guides/attach-a-resource/#if-it-doesnt-work).
