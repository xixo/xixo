# Agents

## Writing

All prose in this repo follows [docs/STYLE.md](docs/STYLE.md), which is based on
the Ruby on Rails guides and organized by [Diátaxis](https://diataxis.fr/). That
includes the docs, the READMEs, and the descriptions the reference pages are
generated from: GraphQL descriptions, MCP tool descriptions, and
`lib/reference_pages`.

- Write plain, declarative sentences in the present tense, in American English
  with the Oxford comma.
- Leave out contrast framing ("X, not Y", "rather than"), closing aphorisms,
  fragments for rhythm, em dashes as general punctuation, metaphor, filler,
  and rhetorical questions.
- Write each page in one Diátaxis mode: the quickstart is a tutorial,
  `guides/` holds how-to guides, `concepts/` holds key concepts, and
  `reference/` is reference.
- `docs/src/content/docs/reference/` is generated by `bin/rails docs:reference`,
  except `environment.mdx`. Change the code the generated pages read, then
  regenerate. Never edit those pages by hand. `environment.mdx` is written by
  hand, and the same task fails when it and the code disagree, so a new
  `ENV` read needs a row there.
- Check every claim against the code before writing it down.
- The repo is public. Leave out real hostnames, addresses, and anything about
  private infrastructure.
